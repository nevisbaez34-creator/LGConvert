# LGConvert

Conversor y descargador de audio y video escrito en Python, usando yt-dlp y FFmpeg.

## Cómo ejecutarlo desde el código

1. Instala Python 3.
2. Instala yt-dlp: `pip install yt-dlp`
3. Descarga FFmpeg (ver THIRD_PARTY_NOTICES.md) y ponlo en el PATH o junto a LGConvert.py.
4. Ejecuta: `python LGConvert.py`
